# Kata 4 — punto de partida de las tres repeticiones

Este es un **esqueleto, no la solución**. Se incluyen únicamente el modelo, los contratos (puertos), el caso de uso, `pom.xml`, `.gitignore` y el servidor de demostración. El objetivo es implementar tres veces, en ramas independientes, las piezas `HttpSeriesService`, `JsonSeriesParser`, `ConsolePresenter`, `Main` y sus pruebas, sin arrastrar infraestructura a la arquitectura. Lee `GUIA_KATA4.md` (entregada por separado).

**Instrucciones rápidas:** `java tools/FibonacciDemoServer.java` inicia el servidor de apoyo en el puerto 8081. `mvn test` valida las clases que ya existen, pero todavía no verifica el objetivo completo de la kata.

> Importante: no presentes este esqueleto como una entrega terminada. La versión final evaluable está en el ZIP de solución, o en la rama `main` después de completar realmente la tercera repetición.
